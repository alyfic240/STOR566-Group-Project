MODELS AND PROTOCOL

Every choice is made on validation data; the test set is used once

Baseline CNN

3 conv blocks, 93,575 parameters, trained from scratch

ResNet-18

11.2M parameters, ImageNet-1k weights, fine-tuned

ViT-B/16

85.8M parameters, ImageNet-21k and -1k weights, fine-tuned

1 · Tune

3 learning rates and 4 noise settings per model, seed 0, validation only

2 · Freeze

chosen settings written to a file before any test evaluation

3 · Train

3 seeds × 6 configurations (3 models, with and without noise)

4 · Test once

original images, 5 noise levels, 5 resolution levels

Selection score S = ½ · accuracy on original + ½ · accuracy on noisy validation images. Reduced resolution is never used to choose anything, so those results measure transfer.
